# Projeto Yello — Instruções para o Claude

## Design de Interfaces

Sempre que for criar, modificar ou revisar qualquer coisa relacionada a design de interface — incluindo sites, landing pages, dashboards, sistemas web, aplicativos, apresentações, componentes UI, e-mails HTML, ou qualquer elemento visual — aplique obrigatoriamente as seguintes skills:

1. **`/frontend-design`** (Anthropic) — define a direção estética: tipografia, cores, animações, composição espacial e atmosfera visual. Evita designs genéricos.
2. **`/web-design-guidelines`** (Vercel Labs) — aplica diretrizes e boas práticas de design web moderno.

### Quando acionar (exemplos):
- "cria um site para..."
- "faz uma landing page..."
- "preciso de um dashboard..."
- "monta uma apresentação..."
- "cria um componente..."
- "faz a interface de..."
- qualquer tarefa que envolva HTML, CSS, React, Vue, Tailwind, ou similar

### Princípios obrigatórios em todo design:
- Nunca usar designs genéricos de IA (gradientes roxos, Inter/Roboto, layouts previsíveis)
- Sempre escolher uma direção estética clara e executar com precisão
- Tipografia distinta e memorável
- Paleta de cores coerente com o contexto
- Animações e micro-interações com propósito
- Código pronto para produção
